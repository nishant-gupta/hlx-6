# EDS conversion log — myastrazeneca.ch replica

Source: AEM core components (wese-hcp-portal-v1 theme). Target: AEM Edge Delivery Services, Document Authoring.
Content: 125 pages (121 captured + 4 locale search-result pages added for dynamics F-2) + 4 nav + 4 footer
fragments, all generated by `tools/importer/import-myastrazeneca.js` (bundle + `run-bulk-import.js`).

Spacers: AEM `<p>&nbsp;</p>` (and a leading `<br>`) are authored as a braille-blank paragraph (U+2800) — the only
encoding that survives the importer's markdown step inside block cells (U+200B/nbsp/br do not; probe in
`stardust/.work/migrate/spacer-test.mjs`).

Teaser titles: the live teaser fills **either** the title or the pretitle slot (476 teasers: never both); an empty
`&nbsp;` pretitle can precede the real title (5 teasers) — the importer takes the slot that carries text.

## Code

- `styles/styles.css` — foundation tokens lifted from the gated canon; section/variant/padding system; buttons;
  Experience Workspace edit-mode repaint; `.azi` icon glyphs (live icomoon codepoints).
- `styles/fonts.css` + `fonts/` — Inter ×3 (OFL), Aleo as **Lexia-sub** (`size-adjust: 98%`), icomoon.
  ⚠️ Lexia is licensed and NOT shipped (`fonts/LICENSING.md`); the stack keeps "Lexia" first for a licensed drop-in.
- `scripts/scripts.js` — `lang` from the path; `applyUnrenderedMetadata()` applies section/page metadata when the
  dev server leaves them unrendered (no-op on the published origin).
- Blocks: header, footer, hero, cards, columns, breadcrumb, social, section-tabs, tabs, form, hcp-gate, accordion,
  table, video, search. Class names are kebab-case (boilerplate lint pattern).

## Residuals (accepted, documented)

- 10px breadcrumb rows ≈3% band diff at 360 — Lexia → Aleo substitution; clears with the licensed font.
- Contact form validation copy and the hidden "Clear Form" reset button are not authored content (definition-driven form).
- Source defects mirrored, not fixed (pure replica): "requestToSignInContent" popup copy, Italian alt texts on DE
  pages, links to live 404s (leberkrebs ×4, EN haematologie), mobile CTA banner overflow.
- Search results come from the EDS query-index (title + description) — index content, not the vendor full-text index.
